### Why this topic exists

Set operations provide the mathematical foundation for manipulating data collections, evaluating Boolean logic expressions, and constructing database queries (such as SQL `UNION`, `INTERSECT`, and `EXCEPT`). Just as numerical arithmetic follows specific algebraic rules, set operations adhere to formal laws. Mastering these properties enables expression simplification, logical proof construction, and query optimization in computer science.

---

### The Four Main Operations

> [!definition] 1. Union ($A \cup B$)
> Contains all elements belonging to $A$, $B$, or both.
>
> **Formal Notation:** $A \cup B = \{x \mid x \in A \lor x \in B\}$
>
> **Example:** If $A = \{1, 2, 3\}$ and $B = \{3, 4, 5\}$, then $A \cup B = \{1, 2, 3, 4, 5\}$.
>
> **CS Parallel:** Corresponds to the logical **OR** ($\lor$) operator and SQL `UNION` command.

> [!definition] 2. Intersection ($A \cap B$)
> Contains only the elements common to both $A$ and $B$.
>
> **Formal Notation:** $A \cap B = \{x \mid x \in A \land x \in B\}$
>
> **Example:** If $A = \{1, 2, 3\}$ and $B = \{3, 4, 5\}$, then $A \cap B = \{3\}$.
>
> **CS Parallel:** Corresponds to the logical **AND** ($\land$) operator and SQL `INTERSECT` command.

> [!definition] 3. Difference ($A - B$ or $A \setminus B$)
> Contains elements that belong to $A$ but do not belong to $B$.
>
> **Formal Notation:** $A - B = \{x \mid x \in A \land x \notin B\}$
>
> **Example:** If $A = \{1, 2, 3\}$ and $B = \{3, 4, 5\}$, then:
> - $A - B = \{1, 2\}$
> - $B - A = \{4, 5\}$
>
> **CS Parallel:** Corresponds to SQL `EXCEPT` or `MINUS`. Note that set difference is non-commutative ($A - B \neq B - A$).

> [!definition] 4. Complement ($A'$ or $A^c$)
> Contains all elements in the Universal Set ($U$) that do not belong to $A$.
>
> **Formal Notation:** $A' = U - A = \{x \mid x \in U \land x \notin A\}$
>
> **Example:** If $U = \{1, 2, 3, 4, 5\}$ and $A = \{1, 2, 3\}$, then $A' = \{4, 5\}$.
>
> **CS Parallel:** Corresponds to the logical **NOT** ($\neg$) operator.

### Properties of Set Operations

These algebraic laws govern set operations, allowing symbolic simplification of set expressions without enumerating individual elements.

#### Commutative Laws
Order does not alter the outcome of a union or intersection:
$$A \cup B = B \cup A$$
$$A \cap B = B \cap A$$

#### Associative Laws
Grouping does not alter the outcome when executing sequential unions or intersections:
$$(A \cup B) \cup C = A \cup (B \cup C)$$
$$(A \cap B) \cap C = A \cap (B \cap C)$$

#### Distributive Laws
Union distributes over intersection, and intersection distributes over union:
$$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$
$$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$

#### Identity Laws
Union with the empty set ($\emptyset$) or intersection with the universal set ($U$) preserves the original set:
$$A \cup \emptyset = A$$
$$A \cap U = A$$

#### Complement Laws
Combining a set with its complement yields boundary sets (the full universe or an empty set):
$$A \cup A' = U$$
$$A \cap A' = \emptyset$$
