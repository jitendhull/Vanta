## 1. JVM Memory Segments

> [!definition] JVM Runtime Data Areas
> - **Heap:** Shared across all threads; stores all object instances and arrays.
> - **Stack:** Thread-isolated; stores local primitive variables and frame execution state.
> - **Method Area / Metaspace:** Class definitions, static variables, bytecode.

> [!valid] OOP Principles
> Encapsulation, Inheritance, Polymorphism, and Abstraction form the four foundational pillars of Java software architecture.
